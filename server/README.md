# Graph layout server

Сервис не хранит состояние. Каждый запрос получает граф и возвращает новый граф.

Запуск из корня проекта:

```sh
node server/index.mjs
```

По умолчанию сервер слушает `http://127.0.0.1:5197`; порт можно изменить через `PORT`.

## Маршруты

### `POST /makeCoordinates`

Тело:

```json
{
	"graph": { "nodes": [{ "id": "group-1", "type": "group", "childrenCount": 20 }], "links": [] },
	"ignoreCurrentCoordinates": false
}
```

Граф текущего запроса рассчитывается одной симуляцией в основном потоке Node.js, без кластеризации.
Для вложенной группы можно отдельно вызвать тот же маршрут. Содержимое `children` серверу не передаётся
и в ответе не возвращается: сервер использует только `childrenCount` (число непосредственных детей).
Сила заряда зависит от `childrenCount`; вручную её задать нельзя.
Сила связей одинакова для всех узлов, независимо от их типа.
В ответе `chargeMultiplier` возвращается только у узлов с `childrenCount`; у обычных узлов поле отсутствует.
При `true` текущие `x` и `y` верхнего графа игнорируются; при `false` используются как начальные координаты.

### `POST /add`

Тело содержит `graph`, `node` и необязательный массив новых `links`. Новый узел получает центр координат своих уже существующих соседей.
Если соседей нет, он попадает в детерминированную свободную точку внешнего кольца. Остальные узлы
не пересчитываются. Например: `{"graph": {"nodes": [], "links": []}, "node": {"id": "custom-1"}, "links": [{"source": "custom-1", "target": "old-1"}]}`.

### `POST /remove`

Тело содержит `graph` и `nodeId`. Узел и все связанные с ним рёбра удаляются, координаты остальных
узлов не меняются.
