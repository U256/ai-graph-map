# Graph layout server

Сервис не хранит состояние. Каждый запрос получает граф и возвращает новый граф.

## Установка и запуск

Для работы требуется Node.js 24 и npm. В каталоге сервера установите зависимости и запустите сервис:

```sh
npm install
npm start
```

По умолчанию сервер слушает `http://127.0.0.1:5197`; порт можно изменить через `PORT`.
