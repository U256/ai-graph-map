# ai-graph-map

Учебная визуализация графа: React 19 + TypeScript + Vite, физика и жесты на d3, сцена на Canvas,
формы на `react-hook-form`. Узлы — научные работы (`node`), цитирующие их патенты (`subNode`) и
группы с вложенным графом (`group`). Данные —
типизированный модуль `src/data/graph.ts`, запроса к серверу нет, загрузка эмулируется.

Структура, конвенции, порядок проверки и известные грабли — в [`AGENTS.md`](./AGENTS.md).

Начальная раскладка выполняется отдельно для компонент связности; малые компоненты собираются в
компактные макрокластеры без добавления связей. Карта не ограничена размером экрана и просматривается
панорамой и зумом.

React управляет панелью и контейнером карты. Начальную раскладку считает worker; `forceGraphView.ts`
создаёт Canvas-сцену и обновляет её без пересоздания при правках данных. Геометрия видимых групп
рассчитывается отдельным worker-ом по viewport: при масштабе ниже 1 выдаётся пустой список, при 1 и
выше вложенные графы раскрываются на Canvas. Расчёт видимости не меняет координаты раскладки.

При добавлении в уже статичную сцену новые узлы усаживаются по разрешённым связям коротким локальным
расчётом: двигаются новые узлы и их непосредственные соседи, а остальные старые узлы временно
закреплены. Layout внешних узлов кешируется по объекту узла, поэтому повторная отрисовка Canvas не
перемеряет неизменившиеся подписи.

## Команды

- `npm run dev` / `npm run build` / `npm run preview` — дев-сервер, сборка (`tsc -b` + Vite), просмотр `dist`.
- `npm run check-types` — только типы; `npm run lint` — prettier + eslint с автофиксом;
  `npm run format:check` — prettier без правок.
- `npm run check:map` — карта репозитория (файл → экспорты → кто импортирует).
- `npm run check:logic` — инварианты графа и видимых групп в Node; `npm run check:ui` — сцена, видимость и жесты в headless
  Chromium (браузер ставится в `.pw/browsers` командой `npm run check:env`); `npm run verify` — всё сразу.
- Хуки в `.git-hooks`, путь подключается скриптом `prepare`; `pre-commit` запускает `npm run lint`.

## Стиль

Prettier (табы, без `;`, одинарные кавычки, 120) и ESLint (airbnb + airbnb-typescript) — значения в
`.prettierrc.mjs` и `.eslintrc.cjs`. Для `src/data/**` лимит `max-lines` отключён: там сгенерированные
данные, а не логика.
