# ai-graph-map

Учебная визуализация графа: React 19 + TypeScript + Vite, физика и жесты на d3, сцена на Canvas,
формы на `react-hook-form`. Узлы — научные работы (`node`), цитирующие их патенты (`subNode`) и
группы с вложенным графом (`group`). Данные — типизированный модуль `src/data/graph.ts`; загрузка
графа эмулируется, а координаты рассчитывает отдельный Node-сервер.

Структура, конвенции, порядок проверки и известные грабли — в [`AGENTS.md`](./AGENTS.md).

Начальная раскладка выполняется одной симуляцией для графа текущего запроса. Карта не ограничена размером
экрана и просматривается панорамой и зумом.
Сервер раскладывает только граф текущего запроса: вместо содержимого группы получает число её
непосредственных детей. Вложенный граф можно передать тому же маршруту отдельно; клиент не
обходит вложенные графы и не запрашивает их раскладку автоматически.

При приближении зумом к группе Canvas запускает одноразовый локальный разлёт:
в расчёт попадают только узлы поблизости, радиус и сила отталкивания масштабируются размером группы.
Исходная серверная раскладка при этом не пересчитывается.

React управляет панелью и контейнером карты. Начальная раскладка запрашивается через `graphApi.ts` у
Node-сервера; Canvas затем хранит её координаты локально. Drag меняет только выбранный узел, а при
приближении к группе запускается короткая локальная симуляция только для узлов поблизости. Обновление
данных останавливает локальное движение и обновляет живую сцену через `updateData`.
Видимые группы при масштабе раскрытия рассчитываются в Web Worker по снимкам сцены с периодическим
debounce; при уменьшении масштаба список сбрасывается, устаревшие ответы не передаются в React.

## Команды

- `npm run dev` / `npm run build` / `npm run preview` — дев-сервер, сборка (`tsc -b` + Vite), просмотр `dist`.
- `npm run check-types` — только типы; `npm run lint` — prettier + eslint с автофиксом;
  `npm run format:check` — prettier без правок.
- `npm run check:map` — карта репозитория (файл → экспорты → кто импортирует).
- `npm run check:logic` — инварианты графа, серверной раскладки и локального движения в Node; `npm run check:ui` — сцена и жесты в headless
  Chromium (браузер ставится в `.pw/browsers` командой `npm run check:env`); `npm run verify` — всё сразу.
- Хуки в `.git-hooks`, путь подключается скриптом `prepare`; `pre-commit` запускает `npm run lint`.

## Стиль

Prettier (табы, без `;`, одинарные кавычки, 120) и ESLint (airbnb + airbnb-typescript) — значения в
`.prettierrc.mjs` и `.eslintrc.cjs`. Для `src/data/**` лимит `max-lines` отключён: там сгенерированные
данные, а не логика.
